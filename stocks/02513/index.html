公司在做什麼

  • 開放平台及 API（雲端部署）：開發者按 token 付費呼叫 GLM 模型；GLM Coding Plan（寫程式助手的月費方案）也歸在這一線ⓘ。FY2025 Coding Plan 付費開發者約 24.2 萬人。
  • 本地化部署：把模型裝進客戶自己的機房，分為企業級智能體、企業級通用大模型、技術服務三線ⓘ。
  • 國際站牌價：GLM-5.3 輸入 1.4、輸出 4.4 美元／百萬 token，Flash 版 0.15／0.5；公司稱 1H26 API 平均售價上升 101%。
  • 算力以購買服務為主：6/30 應付算力服務費 14.27 億元；公司稱國產晶片推論集群至少 10 萬顆。
